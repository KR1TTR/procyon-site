What it does

WSJT-X's decoder, a modern screen

Procyon uses WSJT-X's own decoder and encoder, so it hears exactly what WSJT-X hears. It just puts a cleaner, friendlier face on it.

Click and the QSO runs itself

Click a station to answer it, or call CQ. Grid, report, roger, 73 and the log entry all happen automatically.

Never miss a caller

Stations calling you are pinned to the top, with an alert, a Reply button and a chime.

POTA activations

Enter your park(s), call CQ POTA, watch the counter reach 10, and get a log file per park, ready for pota.app.

Upload to QRZ and LoTW

One click sends new QSOs. Nothing goes out until you click, so it works offline in the field too.

Works with your other tools

GridTracker, JTAlert and loggers work as they do with WSJT-X. Run it from a tablet on your home network too.

Download

You also need WSJT-X installed: Procyon uses its decoder. Close WSJT-X while Procyon runs.

Linux Mint, Ubuntu, Debian, Raspberry Pi OS The .deb file. Double-click it, then start Procyon from your menu.
Arch, Manjaro, EndeavourOS The -arch.tar.gz file. Unpack it, then run makepkg -si inside.
Other Linux The -linux.zip file. Unzip it and run ./setup.sh.
Windows 10/11 The -windows.zip file. Right-click → Extract All first, then double-click Procyon.bat. Python is included.
macOS 11+ The .dmg file. Drag Procyon to Applications. The first time: System Settings → Privacy & Security → Open Anyway.

Get the latest release

Want to look around first? Start it in demo mode (Procyon DEMO ONLY - no radio on Windows, or Settings → Advanced → Demo band): a simulated band, nothing is transmitted.

Procyon is a hobby project, offered free and as is. Use at your own risk, and always keep an eye on your transmitter.
