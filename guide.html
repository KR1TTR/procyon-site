Before you transmit: make your first tests into a dummy load or at low power, and only transmit with a valid amateur radio license, within your privileges. Procyon is provided as is, without warranty: use it at your own risk.

1. What you need

  • A radio that can work in a data or USB mode on the HF bands (or VHF).
  • An audio connection between radio and computer. One of:
    • a radio with built-in USB audio (IC-7300, IC-705, FT-991A, FT-710, TS-590SG and many more): one USB cable carries sound and radio control;
    • an interface such as a Digirig or SignaLink, with its own sound card;
    • audio cables into the computer's own sound card (works, but an interface is easier).
  • Radio control (CAT), recommended: a USB or serial cable so Procyon can set the frequency and key the transmitter. Without it, Procyon can still work using the radio's VOX.
  • WSJT-X installed (free). Procyon uses its FT8 decoder and encoder, and the Hamlib radio-control tools that come with it. You don't need to run WSJT-X; in fact, close it while Procyon runs, since they can't share the radio and sound card.
  • An accurate clock: FT8 needs your computer's time within about a second (see step 3).

2. Install Procyon and WSJT-X

Linux Mint, Ubuntu, Debian, Raspberry Pi OS

  1. Install WSJT-X: from your software manager, or the .deb from the WSJT-X website (wsjt.sourceforge.io).
  2. Install Procyon: double-click procyon_X.Y.Z_all.deb, or in a terminal: 
    sudo apt install ./procyon_X.Y.Z_all.deb
  3. Allow yourself to use serial ports (needed for radio control on a fresh Linux install): 
    sudo usermod -aG dialout $USER
    then log out and back in (or restart). You only do this once per computer.
  4. Start Procyon from your applications menu. It opens in your web browser.

Windows 10/11

  1. Install WSJT-X with its Windows installer from wsjt.sourceforge.io.
  2. Double-click Procyon-X.Y.Z-windows-setup.exe. If Windows says "Windows protected your PC", click More info then Run anyway. No administrator password is needed.
  3. Start Procyon from the Start menu. It opens in your web browser; there's no window of its own. Press its Quit button (top right) to close it. To update, run the newer setup file the same way - your settings and logbook are kept.

Procyon DEMO ONLY - no radio (also in the Start menu) starts a simulated band for practice. For real operating, always use Procyon. To remove Procyon: Settings → Apps → Procyon → Uninstall.

Prefer not to install? Procyon-X.Y.Z-windows.zip runs from any folder: right-click it, Extract All (it won't run from inside the zip), then double-click Procyon.bat. That way a small window stays open while Procyon runs; closing it stops Procyon.

macOS 11 or newer

  1. Open Procyon-X.Y.Z-macos.dmg and drag Procyon to Applications (or double-click the .pkg).
  2. The first time, macOS blocks it because it isn't signed yet: open System Settings → Privacy & Security, scroll down and click Open Anyway.
  3. If WSJT-X is missing, Procyon offers to install it for you.

Arch Linux and other Linux

Arch: unpack the -arch.tar.gz and run makepkg -si in its folder; install wsjtx and hamlib too. Other distributions: unzip the -linux.zip and run ./setup.sh, which checks what's missing and adds a menu entry. On both, add yourself to the serial-port group as above (dialout; on Arch it's uucp).

3. Set your clock

FT8 transmissions start on the second, every 15 seconds. If your clock is more than about one second off, other stations can't decode you, and you'll decode fewer of them.

  • Linux: usually automatic. Check with timedatectl: it should say "System clock synchronized: yes".
  • Windows: Settings → Time & language → Date & time → turn on "Set time automatically" and press Sync now. Windows' own syncing can drift; many FT8 operators add a small time-sync program.
  • macOS: System Settings → General → Date & Time → "Set time and date automatically".

Procyon's Band activity list shows each station's time offset (DT). If most stations show around +1 or more, your clock is off.

4. First start: Settings

On the first start, Settings opens by itself (the gear icon at the top right brings it back).

  1. Coming from WSJT-X? Click Import settings from WSJT-X at the top. It fills in your callsign, grid, radio, serial port, baud, PTT and sound card. Check it over, then press Save.
  2. Station & radio: enter your callsign and grid square.
  3. Turn on Control my radio, then press Detect my radio: Procyon asks each USB port which radio is there (Yaesu, Kenwood, Elecraft and Icom radios answer) and fills in the model, port and baud. If it can't tell, start typing your radio's name in the Radio box and pick it, then choose the serial port and baud.
  4. Press Test radio. It only reads the frequency and mode; it never transmits. "Radio answered: 14.074000 MHz" means radio control works.
  5. Radio mode for FT8: leave it on Data (DATA A on Elecraft, USB-D on Icom).
  6. Transmit (PTT) by: usually CAT command to the radio. See step 5 for interfaces that key the radio themselves.
  7. Audio: choose the radio's sound card for both Input (from radio) and Output (to radio). It's often called "USB Audio CODEC" (built-in radio audio, SignaLink) or "USB Audio Device" (Digirig).
  8. Press Save.

Demo band (Settings → Advanced) lets you practice with simulated stations: nothing is transmitted, QSOs go to a separate practice log, and it's always off again when Procyon starts.

5. Common radio setups

Radio with built-in USB audio (IC-7300, IC-705, FT-991A, FT-710 and similar)

  • One USB cable from radio to computer. Install the radio maker's USB driver first on Windows if it asks.
  • Audio in and out: the radio's sound card ("USB Audio CODEC").
  • PTT: CAT. Radio mode: Data.
  • On the radio, make sure data mode takes its audio from USB (on Icoms: the "DATA MOD" setting = USB).

Digirig

  • The Digirig's USB cable carries both its sound card ("USB Audio Device") and a serial port for CAT (shown as "CP210x", with "(e.g. Digirig)" in Procyon's list).
  • PTT: CAT if your cable carries radio control, or RTS line on the serial port if the Digirig keys the radio itself.

SignaLink USB

  • The SignaLink has its own sound card ("USB Audio CODEC"): choose it for input and output.
  • It keys the radio by itself when it hears audio, so PTT can be VOX. If you also have a CAT cable, CAT is more reliable: Procyon keys the radio directly and the SignaLink only carries audio.
  • Use the SignaLink's TX and RX knobs together with Procyon's levels (step 6); keep its DLY knob low.

Elecraft KX3 / KX2

  • In DATA mode, set the radio's receive filter wide (about 3 kHz). A narrow filter shows up in Procyon as a mostly white waterfall and hides every station outside a small window.
  • The KX3's AF gain sets the receive level when audio comes from its headphone jack.

6. Set the audio levels

Receive: the "RX audio" meter at the top

Hover over RX audio to see the level. Aim for about -30 dB. Adjust it with the radio's AF/volume or line-out setting (or the interface's RX knob), not in Procyon. Between about -40 and -15 decodes fine.

Transmit: the "TX audio drive" slider

Into a dummy load or at low power.
  1. Press Tune: Procyon sends a steady tone and keys the radio.
  2. Watch the radio's ALC meter and move TX audio drive until the ALC barely moves (on many radios: no ALC, or the first few bars; follow your radio's manual for data modes).
  3. Press Tune again to stop.

Too much drive overdrives the transmitter and makes a wide, dirty signal. The radio's power setting, not the drive, sets your output power.

7. Your first QSO

  1. Pick a band from the frequency button at the top (20 m, 14.074 MHz, is a good start in daytime).
  2. Watch Band activity fill in every 15 seconds. Stations calling CQ have a green bar. (The FT8 / FT4 switch beside the frequency picks the mode. Start with FT8: it's where most stations are. FT4 runs faster 7.5-second cycles.)
  3. To answer one, click its row. Procyon sets everything up and transmits in the right time slot. Or press Call CQ and wait for someone to answer.
  4. Follow the exchange in the QSO panel. When it completes, the contact is logged automatically.
  5. Halt stops a transmission straight away.

Finished? Press Quit (top right), or just close Procyon's tab: transmitting stops after 10 seconds, and Procyon closes itself after a minute (you can switch that off in Settings → Advanced).

Uploading: set up QRZ (and LoTW, if you use TQSL) under Settings → Logbook; an upload button appears next to Export ADIF.

8. If something doesn't work

What you seeWhat to try
Decoding works but the radio doesn't respond (Test radio fails), on Linux Add yourself to the serial-port group: sudo usermod -aG dialout $USER, then log out and back in. On Ubuntu and Mint, a braille-display service (brltty) can grab USB serial adapters; if you don't use a braille display, sudo apt remove brltty and unplug/replug the cable.
"The serial port is in use by another program"Close WSJT-X (or other radio software) and try again.
Test radio says the radio didn't answer Check the radio model, port and baud. The baud must match the radio's own CAT/RS232 menu setting. Try Detect my radio.
No decodes at all Check the input sound card, the RX audio level, that the radio is in the right mode and band, and your clock (step 3).
The waterfall is mostly whiteThe radio's receive filter is set very narrow: widen it to about 3 kHz.
Procyon won't transmit Is the Demo band on (striped banner on the waterfall)? Check Transmit (PTT) by: with an interface that keys the radio itself, use VOX, or CAT if you have a CAT cable. Check the output sound card.
The radio keys but sends little or no power Raise TX audio drive, the interface's TX knob, or the radio's data input level; check the radio is in DATA/USB mode.
Stations don't decode me / I decode few stationsCheck the clock (step 3).
Strange stations "calling you" that don't exist Decodes marked with a ? were partly guessed by the decoder and are sometimes just noise; Procyon doesn't alert you for them.
GridTracker or JTAlert don't see Procyon Settings → Network → Companion apps: on, address 127.0.0.1, port 2237. It's paused in demo mode.
Importing into another logging program creates duplicates Settings → Advanced → Logbook export: "Export ADIF: only QSOs not exported before".
Remote access from a phone or tablet doesn't connect Guest and some ISP Wi-Fi networks keep devices apart ("client isolation"); try your home network or a wired connection.
Procyon doesn't open when started from the menu (Linux) A desktop notification says why. Procyon's messages are also saved in ~/.local/share/procyon/procyon.log; or run procyon in a terminal to watch them. To stop Procyon, use the Quit button (top right).
